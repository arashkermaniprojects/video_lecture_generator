ABOUT THIS GUIDE
----------------

lecture on Recurrence Relations for BCS 309 — Algorithms I. The full teaching
instructions are split across module files in this folder.

Files in this folder:
  00_master.txt                   <- You are here. Overall flow + agent prompt.
  01_prologue_intro.txt           <- Prologue: motivation + intro section usage
  02_module_recursion_tree_basics.txt <- Act 1: Recursion Tree — Binary Search, Merge Sort
  03_module_recursion_tree_exp.txt   <- Act 2: Recursion Tree — Fibonacci, Hanoi, Memoization

  05_module_substitution.txt      <- Act 4: Substitution Method tab
  06_epilogue_summary.txt         <- Epilogue: wrap-up + connections


AGENT PROMPT
------------
You are an AI teaching assistant delivering a 50-minute interactive lecture on
Recurrence Relations for an undergraduate Algorithms I course (BCS 309). You
have access to a single-page interactive HTML tool
(Recurrence_Relations_Explorer.html) that contains a collapsible introduction
section and three tabbed interactive modules.

Your job is to guide students through every part of this tool in a structured,
progressive way. For each act, read the corresponding module file from this
folder. Each file tells you:
  - WHAT to show on screen (which tab, which element to click, which slider
    to adjust, which preset to select)
  - WHAT to say (the pedagogical point to make)
  - WHEN to pause for student interaction or questions
  - WHAT to demonstrate live (specific preset selections, button clicks, animations)

Assume students know basic programming (loops, recursion concept) and Big-O
notation basics, but have never formally analyzed recurrence relations, the
Master Theorem, or the substitution method.

COLOUR CODING (consistent across all modules)
----------------------------------------------
  Blue   (#6aa9ff)  — O(log n) algorithms, recursion nodes, induction steps
  Green  (#64f0c8)  — O(n) / memoized, success, Case 2 (balanced), proofs verified
  Yellow (#ffd166)  — O(n log n) algorithms, warnings, pivot elements
  Red    (#ff5c7a)  — O(2^n) exponential, danger, duplicate calls, failed cases
  Orange (#ff9f43)  — intermediate complexity, Tower of Hanoi disks
  Purple (#c77dff)  — Quick Sort partitions, special cases


TAB STRUCTURE
-------------
The tool's left panel has a tab bar with three tabs:
  Recursion Tree | Master Theorem | Substitution

Clicking a tab switches both the left control panel and the right
visualisation panel simultaneously. Each module file documents the
components in both panels for that tab.


KEY INTERACTIVE ELEMENTS
------------------------
1. Recursion Tree tab:
   - Algorithm Preset dropdown (Binary Search, Fast Exp, Merge Sort, Quick Sort,
     Fibonacci naive, Fibonacci memoized, Tower of Hanoi, Custom)
   - Parameters: a (branches), b (divisor), k (work exponent), n (input size)
   - Animation: Play, Pause, Step, Reset buttons
   - Speed slider
   - Algorithm info card with SVG diagram
   - Stats: Levels, Total Nodes, Branching, Leaf Nodes, Complexity
   - Algorithm Simulation panel (appears for some presets)
   - Tree SVG with level-by-level animation
   - Tree summary table (work per level)
   - Insight box (pedagogical commentary)

2. Master Theorem tab:
   - Parameters: a, b, k
   - Analyze button
   - Comparison bar: log_b(a) vs k
   - Three case cards (highlighted when active)
   - Classic examples table
   - Quick example buttons: Binary Search, Merge Sort, Case 1, Case 3

3. Substitution tab:
   - Example preset dropdown (Binary Search, Merge Sort, Fibonacci memo,
     Fibonacci naive, Tower of Hanoi)
   - Step controls: Next Step, Prev, Show All, Reset
   - Step cards that reveal one at a time
   - Progress tracker
